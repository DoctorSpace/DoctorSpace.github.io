# Isadora Shop Frontend

Фронтенд интернет-магазина аксессуаров Isadora на React, TypeScript и Vite.

## Команды

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

Публикация на GitHub Pages выполняется командой `npm run deploy`. Изображения товаров хранятся в `public/images/Products`.
